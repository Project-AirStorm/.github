# Airstorm GFS Chat Feature

## Overview

The Chat feature allows users to communicate with team members in real-time. It supports both one-on-one conversations and group chats with multiple members.

## Features

### Starting New Conversations

To start a new conversation:

1. Click the "New Chat" button in the top-right corner of the chat page
2. Search for and select users you want to chat with
3. Optionally check "Create Group Chat" to create a group conversation
4. Click "Start Chat" to begin the conversation

### Group Chat Management

Group chats offer several management features:

- **Rename**: Click the edit icon next to the group name
- **Add Members**: Use the user-plus icon to add new members to the group
- **Remove Members**: Use the user-minus icon to remove members from the group
- **Leave/Delete**: Use the trash icon to leave or delete a conversation

### Chat Notifications

Unread messages are indicated with a badge on the Chat icon in the sidebar. When you open a conversation, messages are automatically marked as read.

## Documentation Assistant

The documentation assistant is available via the chat bubble in the bottom-right corner of the screen. You can use it to:

- Ask questions about application features
- Get help with specific functionality
- Search for information in the documentation

The assistant processes your questions and provides answers based on the application's documentation.

## Troubleshooting

If you encounter issues with the chat feature:

1. Ensure you have a stable internet connection
2. Check that you have the necessary permissions to access the chat
3. Try refreshing the page if messages aren't loading
4. Contact the system administrator if problems persist

## Technical Details

The chat feature uses Stream Chat API for real-time messaging capabilities. Messages are securely stored and transmitted with end-to-end encryption.
